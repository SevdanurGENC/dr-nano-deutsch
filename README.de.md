> **Hinweis:** Die App richtet sich an türkischsprachige Lernende. Die Oberfläche gibt es auf Türkisch und Englisch, Bedeutungen und Erklärungen jeweils in beiden Sprachen. Menüpunkte werden hier mit ihrer englischen Bezeichnung genannt.

## Was steckt drin?

**📖 Alltagsgeschichten.** 60 kurze Geschichten aus dem echten Leben: Café, Bahnhof, Arztbesuch, Vorstellungsgespräch und vieles mehr. Jede Geschichte hat drei Schritte:
1. Neue Wörter kennenlernen und anhören.
2. Die Geschichte lesen. Ein Tipp auf ein beliebiges Wort zeigt Bedeutung und Aussprache.
3. Das Quiz mit 5 Fragen zu 80 % bestehen.

**📘 Tägliche Lektionen.** 60 Lektionen, vom Alphabet über Zahlen und Uhrzeiten bis zur Grammatik auf B1-Niveau. Jede Lektion enthält eine kurze Erklärung, Beispiele mit Audio und eine Übung mit 5 Fragen. Die Lektionen werden der Reihe nach freigeschaltet.

**🔊 Aussprache.** Zu jedem Wort gibt es eine Lautschrift in türkischen Buchstaben, die betonte Silbe steht in Großbuchstaben (`ŞPAY-ze-kar-te`). Außerdem lässt sich jedes Wort mit der deutschen Stimme des Geräts anhören.

**🎮 Fünf Minispiele:**
- Match Up (Paare finden)
- Quick Pick (Schnellauswahl)
- Letter Master (Buchstaben ordnen)
- Article Hunt (der/die/das)
- Listen & Find (Hören und finden)

Schwache Wörter kommen häufiger dran, kürzlich geübte Wörter treten in den Hintergrund. So wiederholen sich die Aufgaben nicht ständig.

**🪜 Stufensystem.** Die nächste Stufe öffnet sich erst, wenn du:
- alle Geschichten und Lektionen der Stufe abgeschlossen hast
- 80 % ihrer Wörter beherrschst
- die Stufenprüfung mit 12 Fragen bestanden hast

**🎨 Oberfläche:**
- Türkisch / Englisch
- Hell / dunkel / Systemeinstellung
- Farbige Artikel: **der** blau, **die** rot, **das** grün

**🔥 Motivation.** Tägliches XP-Ziel, Tagesserie und Wochenkalender.

**📴 Offline.** Kein Internet nötig. Schriften und alle Inhalte sind in der App enthalten.

## Installation

### Android (APK)

1. Lade die neueste `DrNanoDeutsch.apk` von der Seite [Releases](../../releases) auf dein Handy.
2. Öffne die Datei. Erscheint „Installation aus unbekannten Quellen zulassen“, erlaube es für die App, mit der du die Datei geöffnet hast.
3. Play Protect warnt eventuell vor einer unbekannten App. Das ist bei Apps außerhalb des Play Store normal; tippe auf **Trotzdem installieren**.
4. Für die Aussprache braucht das Handy eine deutsche Stimme: **Einstellungen → Sprachausgabe (Text-in-Sprache) → Google Text-in-Sprache → Deutsch**, dann die Stimme herunterladen.

Voraussetzung: Android 7.0 (API 24) oder neuer.

## Web-Version (GitHub Pages)

Die ganze App ist eine einzige HTML-Datei im Ordner `docs/` und läuft daher auch im Browser.

1. Öffne das Repository auf GitHub: **Settings → Pages**.
2. Wähle **Source:** *Deploy from a branch* · **Branch:** `main` · **Folder:** `/docs` und speichere.
3. Nach ein paar Minuten ist die App unter `https://<dein-benutzername>.github.io/dr-nano-deutsch/` erreichbar.

Auf dem Handy kannst du sie über **Zum Startbildschirm hinzufügen** im Browser wie eine App nutzen.

> Web-Version und Android-App speichern den Fortschritt getrennt. Zum Übertragen nutzt du **Settings → Copy backup / Restore backup**.

## Projektstruktur

```
dr-nano-deutsch/
├── docs/                      ← Die App selbst (Web + APK-Inhalt)
│   ├── index.html             ← Gesamte Oberfläche, Inhalte und Spiellogik
│   ├── fonts/                 ← Baloo 2 + Nunito (offline, OFL-Lizenz)
│   └── icon.png
├── android/                   ← Android-Hülle (Apktool-Projektformat)
│   ├── AndroidManifest.xml
│   ├── apktool.yml            ← minSdk 24, targetSdk 34, Versionsnummer
│   ├── res/                   ← Symbole, Farben für helles/dunkles Design
│   └── smali/com/drnano/deutsch/
│       ├── MainActivity.smali ← Vollbild-WebView, Zurück-Taste
│       ├── Bridge.smali       ← JS ↔ Android-Brücke (TTS, Zwischenablage, Beenden)
│       ├── Listener.smali     ← Meldet das Ende der Sprachausgabe
│       └── Done.smali
├── scripts/build-apk.sh       ← APK mit einem Befehl bauen
└── .github/workflows/build-apk.yml  ← Automatische Builds mit GitHub Actions
```

### So funktioniert es

- **Oberfläche:** Die gesamte App ist eine einzige HTML/CSS/JS-Datei ohne externe Abhängigkeiten.
- **Android-Hülle:** Öffnet den Ordner `docs/` über `file:///android_asset/` in einer Vollbild-WebView.
- **Sprachausgabe:** Die Android-WebView unterstützt `speechSynthesis` aus dem Browser nicht. Deshalb geht die Aussprache über die Brücke `window.AndroidTTS` an die **TextToSpeech**-Engine des Handys. Im Browser nutzt die App direkt die Web Speech API.
- **Warum nicht Kotlin/Gradle:** Die Hülle besteht nur aus vier kleinen Klassen. So lässt sich das Projekt nur mit Java bauen, ganz ohne Android Studio oder Android SDK.

## APK selbst bauen

Du brauchst nur **Java 11+** (und beim ersten Lauf Internet, um die Build-Werkzeuge von GitHub zu laden).

```bash
bash scripts/build-apk.sh
# → dist/DrNanoDeutsch.apk
```

Das Skript macht der Reihe nach Folgendes:
1. Lädt [Apktool](https://github.com/iBotPeaches/Apktool) und [uber-apk-signer](https://github.com/patrickfav/uber-apk-signer) herunter.
2. Kopiert den Inhalt von `docs/` in den Ordner `assets/` der APK.
3. Baut die APK, richtet sie aus (zipalign) und signiert sie mit v2/v3-Signatur.

Mit Versionsnummer:

```bash
VERSION_CODE=2 VERSION_NAME=1.1 bash scripts/build-apk.sh
```

### Automatische Builds mit GitHub Actions

Sobald du ein Tag wie `v1.1` pushst, baut der Workflow die APK und hängt sie an die Seite **Releases** an:

```bash
git tag v1.1
git push origin v1.1
```

Manuell startest du ihn unter **Actions → APK derle → Run workflow**.

## Signieren und Updates

Android installiert ein Update nur dann über die vorhandene App, wenn beide mit **demselben Schlüssel** signiert sind. Ändert sich der Schlüssel, musst du die App deinstallieren und neu installieren, und der Fortschritt geht verloren. Deshalb:

- Lade die Schlüsseldatei `drnano.jks` **niemals** ins Repository hoch (`.gitignore` verhindert das bereits).
- Bewahre Schlüssel und Passwort sicher auf (Passwortmanager oder persönliche Cloud).

Schlüssel für einen lokalen Build verwenden:

```bash
KEYSTORE=~/drnano.jks KEYSTORE_PASSWORD='dein-passwort' KEY_ALIAS=drnano bash scripts/build-apk.sh
```

Damit GitHub Actions mit demselben Schlüssel signiert, lege unter **Settings → Secrets and variables → Actions** diese Secrets an:

| Secret | Wert |
|---|---|
| `KEYSTORE_BASE64` | Ausgabe von `base64 -w0 drnano.jks` (unter macOS: `base64 -i drnano.jks`) |
| `KEYSTORE_PASSWORD` | Keystore-Passwort |
| `KEY_ALIAS` | `drnano` |
| `KEY_PASSWORD` | Schlüsselpasswort (meist identisch mit dem Keystore-Passwort) |

Fehlen diese Secrets, wird die APK mit einem Debug-Schlüssel signiert. Eine solche APK lässt sich nicht als Update über eine mit dem Release-Schlüssel installierte App installieren.

## Neue Geschichte oder Lektion hinzufügen

Alle Inhalte stehen in JavaScript-Arrays in `docs/index.html`.

### Geschichte

```js
{id:'cafe', e:'☕', t:{de:'Im Café', tr:'Kafede', en:'At the Café'},
 w:[ // [Deutsch, Artikel ('der'|'die'|'das'|'pl'|''), Türkisch, Englisch, Aussprache, (gebeugte Formen)]
   ['Kaffee','der','kahve','coffee','KA-fe'],
   ['heißen','','adı … olmak','to be called','HAY-sın',['heiße','heißt']]
 ],
 l:[ // [deutsche Zeile, Türkisch, Englisch] — {geschweifte Klammern} markieren ein Lernwort
   ['Guten Morgen! Einen {Kaffee}, bitte.','Günaydın! Bir kahve, lütfen.','Good morning! A coffee, please.']
 ]}
```

Füge die Geschichte in das Array `s:[…]` der passenden Stufe ein. Bedeutungen nicht markierter Wörter kommen aus dem Wörterbuch `GLOSS`; fehlt ein Wort dort, erscheint es als normaler Text. Neue Wörter trägst du in `GLOSS` als `wort:['Türkisch','Englisch','AUS-spra-che']` ein.

### Lektion

```js
{id:'sein', lv:0, e:'🙋', t:['Şahıs zamirleri ve "sein"','Pronouns & "sein"'],
 i:['Kurze Einleitung (TR)','Kurze Einleitung (EN)'],
 b:[{h:['Başlık','Heading'], p:['Erklärung mit **fett**','Explanation'],
     x:[['ich bin','İH BİN','ben -im','I am']]}],      // [Deutsch, Aussprache, TR, EN]
 q:[{s:'Ich ___ müde.', o:['bin','bist','ist']},      // die ERSTE Option ist die richtige Antwort
    {q:['Soru (TR)','Question (EN)'], o:[['evet','yes'],['hayır','no']]}]}
```

`lv` legt die Stufe fest (0 = A1.1 … 4 = B1). Die Reihenfolge innerhalb der Stufe steht im Array `ORDER`. Die Antworten werden jedes Mal gemischt, schreibe die richtige Antwort also immer **zuerst**.

## Daten und Datenschutz

- Die App hat keinen Server, kein Konto und keine Analyse-Tools.
- Der Fortschritt (Stufe, Wortbeherrschung, Serie, XP) wird nur im `localStorage` des Geräts unter dem Schlüssel `drnano-deutsch-v1` gespeichert.
- Die Android-Version deklariert die Berechtigung `INTERNET`, sendet aber keinerlei Daten ins Netz. Alle Inhalte und Schriften sind in der App enthalten.
- Eine Sicherung erstellst du mit **Settings → Copy backup**. Dabei wird dein Fortschritt als Klartext (JSON) in die Zwischenablage kopiert; mit **Restore backup** lädst du ihn wieder.

## Häufige Probleme

| Problem | Lösung |
|---|---|
| Kein Ton | Lade die deutsche Stimme unter **Einstellungen → Sprachausgabe** herunter. Prüfe, ob das Handy stumm geschaltet ist. |
| Fehler „App nicht installiert“ | Es ist eine ältere, mit einem anderen Schlüssel signierte Version installiert. Erst sichern, alte Version deinstallieren, dann neu installieren. |
| Fortschritt weg | Die App-Daten wurden vermutlich gelöscht. Lade deine letzte Sicherung mit **Restore backup**. |
| Kein Ton in der Web-Version | Browser oder Betriebssystem haben keine deutsche Stimme. Chrome und Safari bringen meist eine mit. |
